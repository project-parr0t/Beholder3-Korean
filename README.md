# Beholder3-Korean
Beholder 3 스팀 게임 AI 기반 한국어 오역 검수 패치

<b> Parr0t 프로젝트는 배포자가 직접 플레이하여 번역을 검수하기에, 문제가 생긴 부분을 보거나 토큰이 부족할 경우 패치가 되지 않는 부분이 존재할 수 있습니다. </b>

## 이게 뭐죠?
해당 깃허브 레포지토리는 parr0t AI 번역 프레임워크를 통해 [Beholder 3](https://store.steampowered.com/app/1570070/Beholder_3/)의 한국어 언어 패치를 적용하는 프로젝트입니다.
parr0t은 조금 더 부드럽고 오역이 적은 AI 기반 게임 번역 프레임워크 코어입니다.

## 바이브 코딩인가요?
네. 게임을 즐기는데 번역까지 일일히 다 하고 싶진 않았습니다.

## 무엇으로 번역했나요?
ChatGPT Codex를 기반으로 ChatGPT 6.1 Luna 서브에이전트를 통해 번역하였으며, ChatGPT 6.1 Sol을 통해 스크립트를 검수하였습니다.

세이프가드로 인해 번역이 중단된 내용은 Deepseek 4.1 Flash와 DeepSeek 4.1 Pro를 통해 1차 폴백으로 번역되었습니다.

## 게임이 안 켜져요 / 게임이 튕겨요!
원본 언어에서 크래시가 발생하는 것이 아니라면 패치 자체의 오류입니다.
이슈를 열고 오류 내용과 상황을 알려주세요, 제 든든한 코덱스 부관이 해결해줄겁니다.

## 기여를 받나요?
물론이죠! 더 나은 번역이 있다면 기여해주세요. 인간 담당자와 ChatGPT 사수와 함께 추가 번역을 검토 후, 반영합니다. 

## 번역되는 게임들에 기준이 있나요?
조직 주인장이 하고 싶은 게임을 번역합니다.

큰 기준은 없으며, 하고 싶은것 위주로 진행되고 있습니다.

## 다운로드 및 설치

[한국어 패치 v1.0.0 다운로드](https://github.com/project-parr0t/Beholder3-Korean/releases/download/v1.0.0/Beholder3-Korean-v1.0.0-Windows-x64-SteamBuild16599828.zip)

지원 환경: Windows x64, Steam Build **16599828**의 **HDRP·URP** 버전.

1. ZIP을 내려받아 게임 폴더 밖의 별도 폴더에 모두 압축 해제합니다.
2. 게임을 종료한 상태에서 `Install-Translation-Patch.bat`를 실행하고 **1. 설치 또는 업데이트**를 선택합니다.
3. 게임의 언어를 **English/영어**로 선택하면 한국어가 표시됩니다.

업데이트할 때는 기존 원본 백업과 `.parr0t` 폴더를 삭제하지 마세요. 다른 패치가 적용되어 설치가 거부된다면 해당 패치의 복원 기능으로 원본을 복구한 뒤 설치하세요.

원본으로 되돌리려면 같은 설치 프로그램에서 **2. 복원**, 적용 상태를 확인하려면 **3. 설치 상태 확인**을 선택합니다.
